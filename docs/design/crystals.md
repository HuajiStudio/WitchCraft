# 水晶、方块与世界生成

**已实现。** 水晶从地下的水晶矿挖出，熔炼后变成魔法水晶；魔法水晶是所有普通法杖的核心材料。

- **水晶矿** `crystal_ore`：生成在 Y 0–63 的石头里，每个区块 20 处、每处最多 8 块。需要石镐以上，掉落 1 个水晶和 3–7 点经验；受时运影响，精准采集掉矿石本身。
- **水晶块** `crystal_block`、**魔法水晶块** `magic_crystal_block`：半透明紫色方块，硬度 5；魔法水晶块发出 15 级光。
- **魔法水晶**可以当燃料：一个烧 2560 秒（256 个物品），一块烧 10 倍。

## 配方

| 产物 | 做法 |
| --- | --- |
| 水晶 | 熔炼水晶矿；或 1 块水晶块拆成 9 个 |
| 水晶块 | 9 个水晶 |
| 魔法水晶 | 熔炼水晶；或 1 块魔法水晶块拆成 9 个 |
| 魔法水晶块 | 9 个魔法水晶；或熔炼水晶块 |
| 普通法杖 | 顶行：材质 + 魔法水晶 + 材质；中间两行居中各一根木棍。材质为木板、圆石类、铁锭、金锭、钻石或红石 |
| 元素法杖 | 顶行：魔法水晶 + 对应的元素水晶 + 魔法水晶；下面同上 |

水晶在其他模组里注册为通用标签 `c:gems/crystal`、`c:ores/crystal` 等，可以互通。

## 元素水晶

**有贴图和名字，但生存模式拿不到。** 七种元素水晶只能从创造模式物品栏拿；用于合成对应的[元素法杖](wands.md#元素法杖)。

贴图和普通水晶形状相同，按普通水晶的明暗换成各自的色调，中间画一个符号：

| 名字 | 物品 ID | 颜色 | 符号 |
| --- | --- | --- | --- |
| 金之水晶 | `metal_crystal` | 金黄 | 圆环（太阳 / 金的炼金符号 ☉） |
| 木之水晶 | `plant_crystal` | 黄绿（避开原版绿宝石的翠绿） | 一片深绿的叶子 |
| 水之水晶 | `water_crystal` | 蓝 | 水滴 |
| 火之水晶 | `flame_crystal` | 橙红 | 火焰 |
| 土之水晶 | `soil_crystal` | 棕 | 山和地平线 |
| 光之水晶 | `light_crystal` | 米白 | 发光的太阳 |
| 影之水晶 | `shadow_crystal` | 暗紫 | 新月 |

## 魔法水晶的特效

**已实现（demo，待测试反馈）。** 魔法水晶和七种元素水晶（普通水晶除外）在物品栏、手上和地上都会轻微上下浮动：振幅半个像素，周期 3 秒。每种元素水晶还可以有自己的特效，目前只有火之水晶有：

- **火之水晶**：中间的火苗像燃烧一样晃动，火尖左右摆、偶尔缩短，共 5 帧，每帧 2 tick。

实现上，这些水晶的物品模型是 `builtin/entity`，由 `MagicItemRenderer` 画出 `models/item/sprite/` 里的普通模型并加上浮动；火苗是贴图动画（`flame_crystal.png.mcmeta`）。以后别的元素水晶要加特效，贴图动画或者在 `MagicItemRenderer` 里加都可以。
