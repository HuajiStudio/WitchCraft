# 法杖

法杖像弓一样按住右键蓄力，松开时扣除魔法值并发射一颗光球。普通法杖每次发射消耗 1 点耐久。

- 光球速度 = 0.5 + 蓄力加成 + 力量附魔等级；蓄力加成和弓一样计算，蓄满 20 tick（1 秒）达到最大值 1。
- 光球不受重力，几乎不减速，默认 5 秒后消失；飞得慢时可以被打回去。
- 光球飞行时身后留下附魔台那样的符文：每 tick 两个，从光球周围半格内飞向它经过的位置。
- 普通法杖破坏蜘蛛网很快，类似剑。

## 已知缺口

- 光球只伤害生物（Mob），不伤害其他玩家。
- 金属法杖没有合成配方；光之法杖的配方要光之水晶，但光之水晶拿不到。两者生存模式下都拿不到。
- 凋零法杖有代码但没注册，游戏里没有这个物品。
