# 法杖

法杖像弓一样按住右键蓄力，松开时扣除魔法值并发射一颗光球。普通法杖每次发射消耗 1 点耐久。

- 光球速度 = 0.5 + 蓄力加成 + 力量附魔等级；蓄力加成和弓一样计算，蓄满 20 tick（1 秒）达到最大值 1。
- 光球不受重力，几乎不减速，默认 5 秒后消失；飞得慢时可以被打回去。
- 光球飞行时身后留下附魔台那样的符文：每 tick 两个，从光球周围半格内飞向它经过的位置。
- 蓄力时，拿法杖的那只手像拉弓时的前手一样指向视线方向，另一只手保持原来的姿势。第一人称下，法杖随蓄力往屏幕中间抬起，蓄满后像弓一样微微颤动。
- 普通法杖破坏蜘蛛网很快，类似剑。

## 外观

所有法杖都是同一种样子：木棍的顶端是一个 L 形托座，开口朝向斜上方，一颗水晶悬空在托座的开口里，和托座隔一个像素。

- 普通法杖的托座是各自的材质（木头、石头、铁、金、钻石、红石），悬空的是魔法水晶。
- 元素法杖的托座是普通水晶的紫色，悬空的是对应的元素水晶。
- 物品栏里是一张完整的平面贴图。在世界里（手上、地上、物品展示框）只画杖身和托座，水晶单独画成一颗缩小的水晶物品，沿杖身方向悬浮在托座上方，和水晶物品一样上下浮动、带着自己的特效（比如火苗晃动）。
- 蓄力时，悬空的水晶随蓄力进度逐渐变白发光，蓄满时完全变白。（试过同时让附魔台符文飞向水晶，但粒子在世界坐标里，很难对准第一人称下画在视角里的水晶，就去掉了。）

## 元素法杖

金木水火土光影七种元素法杖（原来的「金属法杖」改名为金之法杖）共用一个类 `ElementWandItem`，各自带一种元素、一种命中效果和魔法消耗。

- 外观见上文：托座是普通水晶的紫色，悬空的是对应的元素水晶。
- 发射的光球带着法杖的元素，贴图是元素水晶的颜色，中间是同样的符号（深色）。元素同步到客户端，存档里存为 `element`。
- 配方都和光之法杖一样：顶行魔法水晶 + 元素水晶 + 魔法水晶，中间两行居中各一根木棍。
- 木、水、火、土、影五种还没设计效果，消耗暂定 2 点，光球命中后直接消失。

## 已知缺口

- 光球只伤害生物（Mob），不伤害其他玩家。
- 元素法杖的配方要元素水晶，但元素水晶在生存模式拿不到，所以元素法杖生存模式下都拿不到。
- 凋零法杖有代码但没注册，游戏里没有这个物品。
