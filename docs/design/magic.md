# 魔法值系统

**已实现。** 每个玩家有一个魔法值，上限 20，每秒恢复 1 点，使用法杖和魔法书时扣除。

| 项目 | 当前设定 |
| --- | --- |
| 上限 | 20 |
| 初始值 | 10 |
| 恢复速度 | 每秒 1 点（每 10 tick 恢复 0.5），满了就停 |
| 死亡后 | 不保留，重生后回到 10 / 20 |
| 创造模式 | 不扣魔法值 |
| 魔法值不够时 | 不发射，快捷栏上方提示「魔法值已耗尽，请及时充能！」 |
| HUD | 屏幕左下角显示「魔法值：10.0 / 20.0」，旁观模式和 F1 隐藏 |

上限目前没有办法提高，也没有道具能直接回魔。
