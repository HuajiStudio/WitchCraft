# WitchCraft 功能设计

这个文件夹是 WitchCraft 功能的唯一描述来源：你改文档，Claude 按改动（`git diff docs/`）改代码，代码实现后再把文档状态更新回来。

## 目录

| 章节 | 内容 |
| --- | --- |
| [魔法值系统](magic.md) | 上限、恢复、HUD |
| [法杖](wands.md) | 蓄力发射、各种法杖的消耗与效果 |
| [附魔](enchantments.md) | 法杖可用的附魔 |
| [水晶、方块与世界生成](crystals.md) | 水晶矿、水晶块、配方与熔炼 |
| [对外事件接口](events.md) | 给其他模组用的事件 |
| [未完成内容](wip.md) | 魔法书、护盾、魔法剑等代码骨架 |
| [想法池 / 待办](ideas.md) | 新想法和待决定的问题 |

## 协作约定

- 每个功能标一个状态：**已实现**、**部分实现**（代码有但没注册或有缺口）、**计划中**（只有想法）。
- 改数值或行为时直接改原文，不用标注改了哪里，git diff 会显示。
- 新想法先写进 [ideas.md](ideas.md)，写清楚「玩家做什么 → 发生什么」即可，数值可以留空，由 Claude 给出建议值。
- 拿不准的地方写一行 `> 待定：……`，Claude 实现前会先问你。
- 某个章节写大了，就把它改成同名子文件夹（例如 `wands.md` → `wands/README.md` + 每种法杖一个文件），并更新上面的目录。

## 基本信息

- 目标版本：Minecraft 1.21.1，NeoForge 21.1，Java 21。
- 模组 ID：`witchcraft`。各章节的「ID」都省略这个前缀。
- 1.12 的旧版保留在 `1.12` 分支。
